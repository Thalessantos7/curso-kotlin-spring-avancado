# 🔵 Curso Kotlin e Spring do ZERO ao Avançado

---

## 📖 Resumo

Este repositório documenta a minha jornada de aprofundamento em engenharia de software backend através do curso "Kotlin e Spring do ZERO ao Avançado". Ele compila desde os fundamentos essenciais da linguagem Kotlin até à aplicação prática avançada no desenvolvimento de um **Marketplace de Livros** (Projeto Mercado Livro). O objetivo é aplicar conceitos sólidos de desenvolvimento, passando pelas estruturas da linguagem, segurança da aplicação, integração com base de dados e testes rigorosos.

---

## 🎯 Tópicos do Curso

* **Fundamentos de Kotlin:** Sintaxe, estruturas e orientação a objetos aplicadas ao Backend.
* **Spring Framework:** Criação de APIs robustas utilizando Spring Boot e Spring Data.
* **Segurança:** Implementação de autenticação, autorização e proteção de rotas com Spring Security.
* **Banco de Dados Relacional:** Modelação, conexão e utilização na prática.
* **Validação de Requisições:** Garantia da integridade dos dados recebidos utilizando Spring Validator.
* **Testes Unitários:** Garantia de qualidade e fiabilidade do código utilizando a biblioteca Mockk.
* **Arquitetura Orientada a Eventos:** Emissão e manipulação de eventos na aplicação.
